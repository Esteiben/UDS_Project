# 🚖 Urban Data Solutions (UDS)

✨ Plataforma de análisis de movilidad urbana con datos reales de taxis de Nueva York.

📊 Visualiza KPIs, genera reportes PDF y detecta alertas automáticamente.

---

## 🛠️ Tecnologías

🐍 Python + Flask  
🐘 PostgreSQL  
📊 Pandas & Matplotlib  
🎨 Bootstrap 5  
---

## 🚀 ¿Cómo ejecutar?

1. Clona el repositorio  
2. Crea un entorno virtual e instala las dependencias  
3. Configura tu base de datos en `config.py`  
4. Ejecuta `python uds_data_manager.py` para cargar los datos  
5. Lanza la app con `python app.py`  
6. Abre http://127.0.0.1:5000

---

## 📁 Dataset

NYC TLC Green Taxi 2023 (>400k registros, 18 columnas)  
https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page
